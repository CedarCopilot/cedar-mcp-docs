## Capabilities

[Slack overview](/slack/overview) · [Complete capabilities](/capabilities/slack).

<Accordion title="Full tool behavior and constraints">

Manage Slack channels and sync live threads. Create/invite only on explicit user request. create-channel takes createChannel:&#123;name,isPrivate?&#125;; private by default, adds the caller. invite-members takes inviteMembers:&#123;channelId,userIds&#125;; workspace members only. invite-external takes inviteExternal:&#123;channelId,email,externalLimited?&#125;; sends one Slack Connect email invitation, pending acceptance/admin approval; post-only by default; caller and bot must already belong. Channel/invite actions require slack:write and provider grants. sync-thread ingests and attaches to a deal under syncThread.

</Accordion>

## Operations and scopes

| Action | Capability | Baseline scope |
| --- | --- | --- |
| `sync-thread` | Ingest a Slack thread into the supported Cedar conversation context. | `slack:read` |
| `create-channel` | Create a channel, private by default, and add the caller. | `slack:write` |
| `invite-members` | Invite existing workspace members to a channel. | `slack:write` |
| `invite-external` | Send one Slack Connect email invitation, pending acceptance/admin approval. | `slack:write` |

Path, account role, feature gates, target ownership, and billing permissions can impose additional requirements.

### syncThread

Pull a specific Slack thread from the connected user's LIVE Slack into an existing deal, where it's stored and attached to the conversation timeline. Get channelId/threadTs from slack-read's search-live first. This INGESTS + ATTACHES only — it does not search.

| Parameter | Type | Required | Details |
| --- | --- | --- | --- |
| `conversationId` | string | Yes | The EXISTING Cedar deal to attach the Slack thread to. format: "uuid" |
| `channelId` | string | Yes | Slack channel id (e.g. "C0123ABC") — from a search-live match. minLength: 1 |
| `threadTs` | string | No | Thread root ts to pull (e.g. "1700000000.123456"). Omit to pull the channel's recent messages.  |

## Channel management parameters

| Parameter object | Fields |
| --- | --- |
| `createChannel` | Required `name`: 1–80 lowercase letters, digits, underscores or hyphens. Optional `isPrivate`, default `true`. |
| `inviteMembers` | Required `channelId` and 1–100 `userIds` for existing workspace members. |
| `inviteExternal` | Required `channelId` and `email`. Optional `externalLimited`, default `true` (post-only access). |

Create channels or invite people only on the user's explicit request. Channel creation and invitations require both the MCP `slack:write` grant and the connected Slack application's relevant channel/Connect scopes. For an external invitation, both caller and bot must already belong to the channel. The result's `inviteExternal.status` is `pending_acceptance`; sending an invitation does not establish membership or acceptance.
