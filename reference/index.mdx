Cedar exposes 40 family tools in this source snapshot, plus `load-skill` and the gated `load-brain-skills`. Each family groups related operations under an `action` or `channel`. Available tools vary by scopes, organization role, and feature flags.

The reference records advertised schemas, including explicitly labeled restricted actions. It does not promise that every advertised operation is authorized. [Download the complete family catalog](/reference/catalog.json).

## Surface boundaries

Boards, graphs, general code execution, Cedar subagent spawning, outbound flow creation, and HeyReach campaign management are not registered external MCP families. Some have Cedar app or separate API surfaces; see [capability boundaries](/getting-started/capability-boundaries).
