## What “available” means

The registry contains 44 external registrations, including staff-only and feature-gated tools, plus 8 documented app-only tool families. Ordinary customer sessions receive a subset determined by scope, role and feature access. Billing administration also has staff checks inside its handler.

Skills add workflow knowledge, not new API authority. All 20 registered skills and 48 named resources are documented. A stale name in a type declaration or skill example is not counted as a callable tool. Use the runtime `tools/list` and skill catalog for the connection you are building against.
