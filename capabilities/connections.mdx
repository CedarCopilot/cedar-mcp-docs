## connection-write

Availability: **external**. [Parameters and responses](/reference/connection-write).

Change how a CONNECTED INTEGRATION behaves. Call config-read read-settings sections:&#91;"connections"&#93; first for the connectionId every change type below needs. CHANGES: (1) update_crm_field_mappings — add/update/remove a mapping between a CRM field and a Cedar field, including template mappings and per-placeholder transforms. Set isMultiPicklist here for Salesforce/Attio multi-selects. Never hand-type allowedValues: options come from config-write sourceFromCrm/link-mapping. (2) update_slack_sync_config — which Slack channels sync into deals, and how new ones are handled. scope="org" (org admin only) sets the org-wide DEFAULT instead of one connection. (3) update_crm_settings — sync/push switches, dealSyncFilter, and dealWriteGuard (never write to HubSpot deals matching a field/value map). (4) update_connection_instructions — standing rules, chat only (background runs never read them; CRM rules go in the crm-updater). REPLACES the existing text in full, so read it first. (5) manage_playbook_webhook — register what FIRES a &lt;trigger type="webhook"&gt; block, e.g. a Slack channel. (6) disconnect_linkedin_seat / disconnect_whatsapp_account — disconnect a seat/line by unipileAccountId. Connecting is human-only; send the user config-read's connectLinks link. (7) update_whatsapp_sync_config — "index every chat" override and/or per-chat consent tracking. (8) resolve_channel_link_proposal — link or dismiss an ambiguous Slack/LinkedIn/WhatsApp channel against a deal (op=resolve), or re-run the org's automatic linking pass (op=sweep). For AOP custom fields, their options, and their CRM field mappings use config-write. For the user's own settings (mail/notification preferences, inbox layout/tabs, task groups, webhook export) use workspace-write. For credentials and MCP servers use systems-write. For playbook, subagent, and resource file edits use write-document.

Single-call family. Baseline scope: `playbook:write`.
